## Installation

```bash
git clone https://github.com/yaochenr/PMC_Data_Mining.git
cd PMC_Data_Mining
pixi install
```

# Usage
There are two ways to use this code:

- keyword search
- DOI-based search

The notebook `notebook/test_mining.ipynb` shows how to use the code.

For supplementary files, see:

- `notebook/process_supplementary_files_protac.ipynb`

The `supplementary_downloader` function is included in the code, but it may not always work well. In that case, you can use the notebook above instead.
